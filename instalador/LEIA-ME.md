# Instalador do Zent Money

Aqui fica o instalador do Windows pronto para uso, versionado junto do código
para ficar visível ao baixar o repositório.

## Como instalar

1. Baixe **`ZentMoney-Setup-2.2.1.exe`** (o arquivo ao lado deste LEIA-ME).
2. Dê **dois cliques** e siga o instalador.
3. Abra o **Zent Money** pelo menu Iniciar ou pelo atalho na Área de Trabalho.

> O Windows pode mostrar um aviso do SmartScreen ("editor desconhecido"), porque
> o instalador não é assinado digitalmente. É só clicar em **Mais informações →
> Executar assim mesmo**.

## Sobre os dados

- 100% locais: seus dados nunca saem do seu computador.
- A única conexão é a consulta opcional das taxas oficiais (Selic/CDI/IPCA).
- Na primeira execução você cria uma senha e escolhe como quer ser chamado.

## Qual versão é esta

(https://github.com/Allann-as/zent-money/releases/latest). Quando sair uma
versão nova, este arquivo é substituído pela mais recente.
